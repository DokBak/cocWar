# 01 要件定義書

[한국어판](../kr/01_요구사항정의서.md)

| 項目 | 内容 |
|---|---|
| プロジェクト | cocWar (アプリ名: War Report) |
| 基準 | Phase 0〜7 の実装内容 (2026-10-16) |
| 状態 | 確定 (2026-10-16) |

## 1. 目的
Clash of Clans(以下 CoC)のプレイヤーが、クラン・プレイヤーの情報やクラン戦の状況をスマートフォンと Web で手軽に確認できるようにする。
- ゲーム内では散らばっていたり見づらかったりする情報を一つの画面にまとめて表示する。例えば、クラン戦の残り攻撃、勝敗の見通し、メンバー別の成績である。
- データは Supercell が提供する公式 API(Clash of Clans API)から取得する。

## 2. 対象ユーザー
| ユーザー | 主な用途 |
|---|---|
| クランのリーダー・サブリーダー | クラン戦中に残り攻撃と勝敗の見通しを確認し、メンバーに声をかける |
| クランメンバー | 自分とクランの戦争成績、ヒーロー・装備のレベルを確認する |
| 他のクランを見るユーザー | タグで他のクランやプレイヤーを調べる |

- 言語: 韓国語、英語、日本語
- 環境: Android、iOS、Web ブラウザ(Flutter の一つのコードで対応)
- ログインはない。タグさえ分かれば誰でも参照できる。

## 3. 用語
| 用語 | 意味 |
|---|---|
| タグ | クランとプレイヤーを区別する固有番号。例: クラン `#2LCQYV0VL`、プレイヤー `#2PLCLPYV` |
| クラン戦 | 二つのクランが対戦する戦争。準備日(1日) → 戦闘日(1日) → 終了 の順に進む |
| リーグ戦(CWL) | クラン戦リーグ。毎月初めに 8 クランが一つのグループになり、7 ラウンドを戦う |
| キャピタル襲撃 | 毎週末に開かれるクランキャピタルの攻撃イベント |
| プロキシサーバー | アプリの代わりに公式 API を呼び出す中継サーバー。公式 API のトークンをアプリに入れないために置く |

## 4. 機能要件

### 4.1 ホーム (検索)
| ID | 要件 | 実装 |
|---|---|---|
| FR-01 | クランまたはプレイヤーのタグを入力して検索できる。`#` がなくても、小文字でも、数字の 0 を英字の O と誤入力しても正しく直して検索する | Phase 3 |
| FR-02 | 不正なタグは画面を移動せず、エラー文言を表示する | Phase 3 |
| FR-03 | 最近の検索を最大 10 件表示する。クランはクラン戦リーグのアイコンと「クラン : 名前」、プレイヤーは対戦リーグのアイコンと「プレイヤー : 名前」で表示する | Phase 3, 6 |
| FR-04 | お気に入りを追加・削除できる(最大 100 件) | Phase 3 |
| FR-05 | Supercell とは無関係の非公式アプリである旨を表示する | Phase 3 |

### 4.2 設定
| ID | 要件 | 実装 |
|---|---|---|
| FR-06 | 言語を システム設定(端末の言語に従う) / 韓国語 / 英語 / 日本語 から選べる。各画面の地球儀ボタンからも変更できる | Phase 3, 4, 6 |
| FR-07 | テーマを ライト / ダーク / システム から選べる | Phase 3 |
| FR-08 | 言語とテーマの選択はアプリを再起動しても保持される | Phase 3 |

### 4.3 クラン
| ID | 要件 | 実装 |
|---|---|---|
| FR-09 | クランのヘッダーにバッジ、名前、タグ(タップでコピー)、レベル、メンバー数、勝/分/敗、連勝、クラン戦リーグ、キャピタルリーグを表示する | Phase 4, 5, 6 |
| FR-10 | メンバー一覧を 役職 → タウンホール → 名前 の順に表示し、タップするとプレイヤー画面に移動する | Phase 5 |
| FR-11 | メンバーカードに今回のキャピタル襲撃の攻撃権使用数(使用/全体)を表示する | Phase 6 |
| FR-12 | 戦争ログ(通常のクラン戦のみ)を 10 件ずつのページで表示する。戦争ログが非公開ならリクエストせず案内のみ表示する | Phase 4 |
| FR-13 | 広い画面(本文 2 列が入る約 1313px 以上)ではクランとメンバーを並べて表示できる | Phase 5 |

### 4.4 プレイヤー
| ID | 要件 | 実装 |
|---|---|---|
| FR-14 | ヘッダーにリーグ、タウンホール、所属クランを表示し、所属クランをタップするとクラン画面に移動する | Phase 5 |
| FR-15 | 統計(トロフィー、最高記録、戦争の星、寄付、受けた寄付、キャピタル貢献など)を表示する | Phase 5, 6 |
| FR-16 | ホームビレッジとビルダーベースのタブで、ヒーロー・装備・兵・呪文のレベルを画像タイルで表示する。最大レベルなら金色、現在のタウンホールで上げられる最高レベルも併せて表示する | Phase 5 |
| FR-17 | ゲーム画像がない場合は代替画像で表示する | Phase 5 |

### 4.5 現在のクラン戦
| ID | 要件 | 実装 |
|---|---|---|
| FR-18 | クランが準備日または戦闘日なら、クラン・プレイヤー画面の下に「クラン戦情報を見る」ボタンを表示する | Phase 6 |
| FR-19 | クラン戦画面に状態(準備日・戦闘日・終了)、残り時間、両クランの星・破壊率・使用した攻撃数を表示する | Phase 6 |
| FR-20 | 戦闘日には勝敗の見通し(リードしている星の数、必要な星、残り攻撃、獲得できる星)を表示する | Phase 6 |
| FR-21 | 自クランと相手クランのメンバー別の攻撃結果と防衛結果を表示する | Phase 6 |

### 4.6 クラン戦リーグ (リーグ戦)
| ID | 要件 | 実装 |
|---|---|---|
| FR-22 | 通常の戦争がなく、リーグ戦の準備日・戦闘日なら「リーグ戦情報を見る」ボタンを表示する | Phase 7 |
| FR-23 | グループ順位を表示する。点数は星に勝利ごとに 10 を加えた値で、同点なら合計破壊率で決める | Phase 7 |
| FR-24 | ラウンドごとの自クランの対戦(相手、状態、結果)を表示し、タップすると対戦詳細(FR-19〜21 と同じ画面)に移動する | Phase 7 |
| FR-25 | メンバー別のシーズン成績(攻撃数、星、平均破壊率、星3の数)を表示する | Phase 7 |
| FR-26 | リーグ戦の期間でなければ「現在はリーグ戦の期間ではありません」と表示する | Phase 7 |

## 5. 非機能要件
| ID | 区分 | 要件 |
|---|---|---|
| NFR-01 | 多言語 | 画面のすべての文言を韓国語、英語、日本語の 3 言語で提供する |
| NFR-02 | エラー処理 | 存在しないタグ、非公開の戦争ログ、リクエスト過多、メンテナンス中、ネットワークエラーを区別して適切な文言を表示し、再試行できるようにする |
| NFR-03 | エラー処理 | エラー時に同じリクエストを自動で繰り返さない(画面の表示遅延とリクエストの蓄積を防ぐ) |
| NFR-04 | 性能 | サーバーは公式 API の応答を短時間保持(キャッシュ)し、同じリクエストを減らす。保持時間は 1 分〜24 時間 |
| NFR-05 | セキュリティ | 公式 API のトークンはサーバーにのみ置き、アプリとリポジトリには入れない |
| NFR-06 | セキュリティ | 公開リポジトリのため、`.env`、トークン、ゲーム画像をコミットしない |
| NFR-07 | 著作権 | ゲーム画像は Supercell の著作物のためリポジトリに含めず、各自ローカルに取得して使う。[ファンコンテンツポリシー](https://supercell.com/en/fan-content-policy/)に従う |
| NFR-08 | 画面 | 本文の幅は 640px に揃え、スマートフォンから Web まで同じレイアウトで表示する |
| NFR-09 | 品質 | 機能ごとに自動テストを置き、コミット前に静的解析(analyze)とテストをすべて通す |

## 6. 制約事項
- **公式 API のトークンは登録した IP からのみ動作する。** そのため、アプリが直接呼び出さず、固定 IP のサーバー(プロキシ)を経由する。
- **公式 API は現時点のデータのみを返す。** 終了した戦争の攻撃詳細、過去のリーグ戦の結果、プレイヤーの変化の記録は取得し直せない。
- **DB がない。** サーバーはメモリに短時間だけ保持し、アプリは設定・最近の検索・お気に入りのみ端末に保存する。そのため、過去の記録は表示できない。
- タウンホール別の最高レベルのように公式 API が提供しない情報は、コミュニティパッケージのデータから作った表を使う。

## 7. 範囲外 (今後検討)
| 項目 | 理由 |
|---|---|
| 過去の戦争・リーグ戦の記録、プレイヤー統計の推移 | DB と定期的な収集が必要 |
| リーグ戦のボーナスメダル数 | リーグごとに異なる表が必要 |
| レジェンドリーグの追跡、プッシュ通知、ホームウィジェット | 今後の候補 |
| 公式 Fan Kit 画像への置き換え、デプロイ | 次の段階で進める(デプロイ手順書とあわせて) |
