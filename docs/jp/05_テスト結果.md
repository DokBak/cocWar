## 5. 今回の Phase で見つけて修正した問題
| 内容 | 原因 | 対応 |
|---|---|---|
| ホームのテスト 1 件が「テスト終了後もタイマーが残っている」で失敗 (Phase 7 の作業中) | ホームのテストの偽 API が `getClan` だけを差し替えていたため、リーググループの取得が実際のネットワークに出て、タイムアウトのタイマーを残した。アプリのコードの問題ではなく、テスト構成の問題 | 偽 API に戦争・リーググループの取得も追加し、実際のリクエストを送らないようにした。テストの基準は下げていない |
| 通常の戦争の取得中にもリーググループを先に取得していた | ボタンが「戦争なし」と「取得中」を区別していなかった | 通常の戦争の取得が終わってからのみリーググループを取得するよう修正した(TC-32) |
