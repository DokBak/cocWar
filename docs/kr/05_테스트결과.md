## 5. 이번 Phase에서 발견하고 고친 문제
| 내용 | 원인 | 조치 |
|---|---|---|
| 홈 테스트 1건이 "테스트가 끝난 뒤에도 타이머가 남아 있음"으로 실패 (Phase 7 작업 중) | 홈 테스트의 가짜 API가 `getClan`만 바꿔 두어, 리그 그룹 조회가 실제 네트워크로 나가며 시간 제한 타이머를 남겼다. 앱 코드 문제가 아니라 테스트 구성 문제 | 가짜 API에 전쟁·리그 그룹 조회도 넣어 실제 요청을 보내지 않게 했다. 테스트 기준은 낮추지 않았다 |
| 리그 그룹을 일반 전쟁 조회 중에도 미리 요청 | 버튼이 "전쟁 없음"과 "조회 중"을 구분하지 않았다 | 일반 전쟁 조회가 끝난 뒤에만 리그 그룹을 조회하도록 고쳤다(TC-32) |
