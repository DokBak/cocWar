# 01 요구사항정의서

[日本語版](../jp/01_要件定義書.md)

| 항목 | 내용 |
|---|---|
| 프로젝트 | cocWar (앱 이름: War Report) |
| 기준 | Phase 0~7 구현 내용 (2026-10-16) |
| 상태 | 확정 (2026-10-16) |

## 1. 목적
Clash of Clans(이하 CoC) 플레이어가 클랜과 플레이어 정보, 클랜전 상황을 휴대폰과 웹에서 쉽게 확인할 수 있게 한다.
- 게임 안에서는 흩어져 있거나 보기 어려운 정보를 한 화면에 모아 보여 준다. 예를 들면 클랜전의 남은 공격, 승패 전망, 멤버별 성적이다.
- 데이터는 Supercell이 제공하는 공식 API(Clash of Clans API)에서 가져온다.

## 2. 대상 사용자
| 사용자 | 주로 하는 일 |
|---|---|
| 클랜 리더·공동대표 | 클랜전 중 남은 공격과 승패 전망을 확인하고 멤버를 독려한다 |
| 클랜 멤버 | 자신과 클랜의 전쟁 성적, 영웅·장비 레벨을 확인한다 |
| 다른 클랜을 보는 사용자 | 태그로 다른 클랜이나 플레이어를 찾아본다 |

- 언어: 한국어, 영어, 일본어
- 환경: Android, iOS, 웹 브라우저(Flutter 하나의 코드로 지원)
- 로그인은 없다. 누구나 태그만 알면 조회할 수 있다.

## 3. 용어
| 용어 | 뜻 |
|---|---|
| 태그 | 클랜과 플레이어를 구분하는 고유 번호. 예: 클랜 `#2LCQYV0VL`, 플레이어 `#2PLCLPYV` |
| 클랜전 | 두 클랜이 맞붙는 전쟁. 준비일(하루) → 전투일(하루) → 종료 순서로 진행 |
| 리그전(CWL) | 클랜전 리그. 매월 초 8개 클랜이 한 그룹이 되어 7라운드를 치른다 |
| 캐피탈 레이드 | 주말마다 열리는 클랜 캐피탈 공격 이벤트 |
| 프록시 서버 | 앱 대신 공식 API를 호출해 주는 중간 서버. 공식 API 토큰을 앱에 넣지 않으려고 둔다 |

## 4. 기능 요구사항

### 4.1 홈 (검색)
| ID | 요구사항 | 구현 |
|---|---|---|
| FR-01 | 클랜 또는 플레이어 태그를 입력해 조회할 수 있다. `#`이 없거나 소문자여도, 숫자 0을 영문 O로 잘못 입력해도 바르게 고쳐서 찾는다 | Phase 3 |
| FR-02 | 잘못된 태그는 이동하지 않고 오류 문구를 보여 준다 | Phase 3 |
| FR-03 | 최근 검색을 최대 10개 보여 준다. 클랜은 클랜전 리그 아이콘과 "클랜 : 이름", 플레이어는 경쟁전 리그 아이콘과 "플레이어 : 이름"으로 표시한다 | Phase 3, 6 |
| FR-04 | 즐겨찾기를 추가하고 지울 수 있다(최대 100개) | Phase 3 |
| FR-05 | Supercell과 관계없는 비공식 앱이라는 고지를 보여 준다 | Phase 3 |

### 4.2 설정
| ID | 요구사항 | 구현 |
|---|---|---|
| FR-06 | 언어를 시스템 설정(기기 언어 따름) / 한국어 / 영어 / 일본어 중에서 고를 수 있다. 각 화면의 지구본 버튼으로도 바꿀 수 있다 | Phase 3, 4, 6 |
| FR-07 | 테마를 라이트 / 다크 / 시스템 중에서 고를 수 있다 | Phase 3 |
| FR-08 | 언어와 테마 선택은 앱을 다시 켜도 유지된다 | Phase 3 |

### 4.3 클랜
| ID | 요구사항 | 구현 |
|---|---|---|
| FR-09 | 클랜 헤더에 배지, 이름, 태그(누르면 복사), 레벨, 멤버 수, 승/무/패, 연승, 클랜전 리그, 캐피탈 리그를 보여 준다 | Phase 4, 5, 6 |
| FR-10 | 멤버 목록을 직책 → 타운홀 → 이름 순으로 보여 주고, 누르면 플레이어 화면으로 간다 | Phase 5 |
| FR-11 | 멤버 카드에 이번 캐피탈 레이드 공격권 사용 수(사용/전체)를 보여 준다 | Phase 6 |
| FR-12 | 전쟁 로그(일반 클랜전만)를 10개씩 페이지로 보여 준다. 전쟁 로그가 비공개면 요청하지 않고 안내만 보여 준다 | Phase 4 |
| FR-13 | 넓은 화면(본문 두 칸이 들어가는 약 1313px 이상)에서는 클랜과 멤버를 나란히 볼 수 있다 | Phase 5 |

### 4.4 플레이어
| ID | 요구사항 | 구현 |
|---|---|---|
| FR-14 | 헤더에 리그, 타운홀, 소속 클랜을 보여 주고, 소속 클랜을 누르면 클랜 화면으로 간다 | Phase 5 |
| FR-15 | 통계(트로피, 최고 기록, 전쟁 별, 기부, 받은 기부, 캐피탈 기여 등)를 보여 준다 | Phase 5, 6 |
| FR-16 | 본마을과 장인기지 탭에서 영웅, 장비, 부대, 주문의 레벨을 이미지 타일로 보여 준다. 최대 레벨이면 금색, 현재 타운홀에서 올릴 수 있는 최고 레벨도 함께 표시한다 | Phase 5 |
| FR-17 | 게임 이미지가 없으면 대체 이미지로 표시한다 | Phase 5 |

### 4.5 현재 클랜전
| ID | 요구사항 | 구현 |
|---|---|---|
| FR-18 | 클랜이 준비일이나 전투일이면 클랜·플레이어 화면 아래에 "클랜전 정보 보기" 버튼을 보여 준다 | Phase 6 |
| FR-19 | 클랜전 화면에 상태(준비일·전투일·종료), 남은 시간, 양 클랜의 별·파괴율·사용 공격 수를 보여 준다 | Phase 6 |
| FR-20 | 전투일에는 승패 전망(앞선 별 수, 필요한 별, 남은 공격, 얻을 수 있는 별)을 보여 준다 | Phase 6 |
| FR-21 | 우리 클랜과 상대 클랜의 멤버별 공격 결과와 방어 결과를 보여 준다 | Phase 6 |

### 4.6 클랜전 리그 (리그전)
| ID | 요구사항 | 구현 |
|---|---|---|
| FR-22 | 일반 전쟁이 없고 리그전 준비일·전투일이면 "리그전 정보 보기" 버튼을 보여 준다 | Phase 7 |
| FR-23 | 그룹 순위를 보여 준다. 점수는 별에 승리마다 10을 더한 값이고, 같으면 총 파괴율로 정한다 | Phase 7 |
| FR-24 | 라운드별 우리 경기(상대, 상태, 결과)를 보여 주고, 누르면 경기 상세(FR-19~21과 같은 화면)로 간다 | Phase 7 |
| FR-25 | 멤버별 시즌 성적(공격 수, 별, 평균 파괴율, 3성 수)을 보여 준다 | Phase 7 |
| FR-26 | 리그전 기간이 아니면 "지금은 리그전 기간이 아닙니다"를 보여 준다 | Phase 7 |

## 5. 비기능 요구사항
| ID | 구분 | 요구사항 |
|---|---|---|
| NFR-01 | 다국어 | 화면의 모든 문구는 한국어, 영어, 일본어 세 언어로 제공한다 |
| NFR-02 | 오류 처리 | 없는 태그, 비공개 전쟁 로그, 요청 과다, 점검 중, 네트워크 오류를 구분해 알맞은 문구를 보여 주고 다시 시도할 수 있게 한다 |
| NFR-03 | 오류 처리 | 오류가 났을 때 같은 요청을 자동으로 반복하지 않는다(화면이 늦게 뜨고 요청이 쌓이는 것을 막는다) |
| NFR-04 | 성능 | 서버는 공식 API 응답을 짧게 보관(캐시)해 같은 요청을 줄인다. 보관 시간은 1분~24시간 |
| NFR-05 | 보안 | 공식 API 토큰은 서버에만 두고 앱과 저장소에 넣지 않는다 |
| NFR-06 | 보안 | 공개 저장소이므로 `.env`, 토큰, 게임 이미지를 커밋하지 않는다 |
| NFR-07 | 저작권 | 게임 이미지는 Supercell 저작물이므로 저장소에 올리지 않고, 각자 로컬에 받아 쓴다. [팬 콘텐츠 정책](https://supercell.com/en/fan-content-policy/)을 따른다 |
| NFR-08 | 화면 | 본문 폭은 640px로 맞추고, 휴대폰에서 웹까지 같은 배치로 보인다 |
| NFR-09 | 품질 | 기능마다 자동 테스트를 두고, 커밋 전에 분석(analyze)과 테스트를 모두 통과시킨다 |

## 6. 제약 사항
- **공식 API 토큰은 등록한 IP에서만 동작한다.** 그래서 앱이 직접 부르지 않고 고정 IP 서버(프록시)를 거친다.
- **공식 API는 지금 시점의 데이터만 준다.** 끝난 전쟁의 공격 상세, 지난 리그전 결과, 플레이어 변화 기록은 다시 받을 수 없다.
- **DB가 없다.** 서버는 메모리에만 잠깐 보관하고, 앱은 설정·최근 검색·즐겨찾기만 기기에 저장한다. 따라서 과거 기록을 보여 줄 수 없다.
- 타운홀별 최고 레벨처럼 공식 API가 주지 않는 정보는 커뮤니티 패키지 데이터로 만든 표를 쓴다.

| 리그전 보너스 메달 수 | 리그마다 다른 표가 필요하다 |
