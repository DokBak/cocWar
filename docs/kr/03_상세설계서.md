## 1. 태그 처리 (공통)
`packages/coc_models/lib/src/tag.dart`

| 함수 | 동작 |
|---|---|
| `normalizeTag(input)` | 공백 제거 → 앞의 `#` 또는 `%23` 제거 → 대문자로 → 영문 `O`를 숫자 `0`으로 → 앞에 `#`을 붙인다. 예: ` 2lcqyvovl` → `#2LCQYV0VL` (`#` 없음, 소문자, 영문 O를 한 번에 고친다) |
| `isValidTag(tag)` | `#` 뒤가 `0289PYLQGRJCUV` 문자로만 3~12자인지 확인한다 |

앱(검색, 화면 주소)과 서버(모든 라우트)가 같은 함수를 쓴다. 정해지지 않은 리그전 경기 태그 `#0`은 이 검사를 통과하지 못한다.

## 2. 서버
`server/lib/src/app.dart`, `server/lib/src/coc_api_client.dart`, `server/bin/server.dart`

### 2.1 라우트
| 우리 서버 주소 | 공식 API 주소 | 쿼리 | 캐시 | 요구사항 |
|---|---|---|---|---|
| `GET /health` | - | - | - | - |
| `GET /clans/<tag>` | `/clans/{tag}` | - | 2분 | FR-09 |
| `GET /clans/<tag>/warlog` | `/clans/{tag}/warlog` | `limit`, `after`, `before` | 5분 | FR-12 |
| `GET /clans/<tag>/currentwar` | `/clans/{tag}/currentwar` | - | 1분 | FR-18~21 |
| `GET /clans/<tag>/currentwar/leaguegroup` | `/clans/{tag}/currentwar/leaguegroup` | - | 5분 | FR-22~26 |
| `GET /clanwarleagues/wars/<warTag>` | `/clanwarleagues/wars/{warTag}` | - | 1분 | FR-24 |
| `GET /clans/<tag>/capitalraidseasons` | `/clans/{tag}/capitalraidseasons` | `limit` | 2분 | FR-11 |
| `GET /leagues` | `/leagues?limit=100` | - | 24시간 | FR-03, FR-09 |
| `GET /players/<tag>` | `/players/{tag}` | - | 2분 | FR-14~17 |

- 처리 순서: 태그 정규화 → 형식 검사(실패하면 400, 공식 API를 부르지 않는다) → 캐시 확인 → 공식 API 호출 → 성공 응답만 캐시에 저장 → JSON으로 응답
- 캐시 키는 `이름|정규화한 태그|쿼리 문자열`이다. 쿼리가 다르면 따로 보관한다.
- 응답 헤더에 `cache-control: public, max-age=<캐시 초>`를 붙인다.
- 모든 응답에 CORS 헤더(`access-control-allow-origin: *`)를 붙이고, `OPTIONS` 요청에는 바로 200으로 답한다. 웹 앱이 다른 주소의 서버를 부를 수 있게 하기 위해서다.

### 2.2 오류 변환
| 공식 API | 우리 서버 응답 | `reason` | 비고 |
|---|---|---|---|
| 403 `accessDenied` | 403 | `accessDenied` | 비공개 전쟁 로그 등 |
| 403 그 밖 (`accessDenied.invalidIp` 등) | 502 | `upstreamAuth` | 서버 토큰·IP 설정 문제. 로그를 남긴다 |
| 400 | 400 | 공식 `reason` 또는 `badRequest` | |
| 404 | 404 | `notFound` | 리그전 기간이 아닐 때도 404 |
| 429 | 429 | `rateLimited` | |
| 503 | 503 | `inMaintenance` | |
| 그 밖 | 502 | `upstreamError` | 로그를 남긴다 |
| 서버 안의 예상 못 한 예외 | 500 | `internalError` | 로그를 남긴다 |

응답 본문 형식: `{"reason": "...", "message": "..."}`

### 2.3 캐시 (`server/lib/src/ttl_cache.dart`)
- 항목마다 만료 시각을 두는 메모리 캐시다. 최대 1000개.
- 가득 차면 만료된 항목을 먼저 지우고, 그래도 가득하면 가장 먼저 넣은 항목부터 지운다.

### 2.4 시작
- 설정은 환경변수를 먼저 보고, 없으면 `.env`를 읽는다. `COC_API_TOKEN`이 없으면 종료 코드 64로 끝난다.
- `PORT`(기본 8080)에서 모든 주소(0.0.0.0)로 요청을 받는다. 요청마다 로그를 남긴다.

## 3. 공유 모델
`packages/coc_models/lib/src/` (freezed + json_serializable, 생성 파일도 커밋한다)

| 파일 | 모델 | 쓰는 곳 |
|---|---|---|
| `clan.dart` | `Clan`, `ClanMember` | 클랜 화면, 홈 이력 |
| `player.dart` | `Player`, `PlayerClan`, `PlayerItem`, `Achievement` | 플레이어 화면 |
| `war_log.dart` | `ClanWarLog`, `ClanWarLogEntry`, `WarClan` | 전쟁 로그 |
| `current_war.dart` | `CurrentWar`, `CurrentWarClan`, `WarMember`, `WarAttack`, `WarState` | 클랜전, 리그전 경기 |
| `league_group.dart` | `ClanWarLeagueGroup`, `LeagueGroupClan`, `LeagueGroupMember`, `LeagueRound`, `LeagueGroupState` | 리그전 |
| `capital_raid.dart` | `CapitalRaidSeasons`, `CapitalRaidSeason`, `CapitalRaidMember`, `RaidState` | 멤버 카드의 레이드 공격권 |
| `common.dart` | `BadgeUrls`, `IconUrls`, `Label`, `League` | 공통 |
| `paging.dart` | `Paging`, `Cursors` | 목록 응답 |
| `coc_date_time.dart` | `CocDateTimeConverter` | `20261013T100000.000Z` 형식 ↔ UTC 시각 |

- 모든 필드는 비어 있을 수 있게(nullable) 두고, 목록은 기본값을 빈 목록으로 둔다. 공식 API가 필드를 빼고 보내도 앱이 멈추지 않게 하기 위해서다.
- 모르는 상태 값은 `unknown`으로 읽는다(`WarState`, `LeagueGroupState`, `RaidState`).
- 전쟁 응답의 타운홀 필드는 `townhallLevel`(h가 소문자)이라 `@JsonKey`로 이름을 맞춘다.

## 4. 앱

### 4.1 공통 (`apps/mobile/lib/core/`)
| 파일 | 내용 |
|---|---|
| `api_client.dart` | 서버 호출(dio, 연결 10초·응답 20초 시간 제한). 오류를 `ApiErrorKind`로 바꾼다 |
| `providers.dart` | `apiClientProvider`, `sharedPreferencesProvider`, 설정(언어·테마), 최근 검색(10), 즐겨찾기(100), `noAutoRetry` |
| `router.dart` | 화면 주소(02 기본설계서 4.1) |
| `layout.dart` | `contentMaxWidth = 640`, `splitViewMinWidth = 640×2 + 1 + 32` |

앱 오류 종류(`ApiErrorKind`):

| 서버 응답 | 종류 | 화면 문구 |
|---|---|---|
| 400 | `invalidTag` | 찾을 수 없음 |
| 403 `accessDenied` | `privateLog` | 전쟁 로그 비공개 |
| 404 | `notFound` | 찾을 수 없음 |
| 429 | `rateLimited` | 요청 과다 |
| 503 | `maintenance` | 점검 중 |
| 응답 없음 | `network` | 네트워크 오류 |
| 그 밖 | `unknown` | 일반 오류 |

### 4.2 화면별 데이터 (Provider)
Provider는 데이터를 불러오고 로딩·오류 상태를 관리하는 Riverpod의 단위입니다. 화면을 닫으면 정리되도록(`autoDispose`) 만들었습니다.

| 화면 | Provider | 내용 |
|---|---|---|
| 클랜 | `clanProvider(tag)` | 클랜 정보 |
| 클랜 | `warLogProvider(tag)` | 전쟁 로그에서 리그전 기록을 뺀 목록. 페이지는 앱에서 10개씩 나눈다 |
| 클랜 | `latestRaidProvider(tag)` | 최근 레이드 1건(`limit=1`). 오류는 null(해당 칸만 숨김) |
| 플레이어 | `playerProvider(tag)` | 플레이어 정보 |
| 플레이어 | `levelCapsProvider`, `itemGroupsProvider`, `gameAssetsProvider` | 레벨 표, 분류 표, 받아 둔 이미지 목록 |
| 클랜전 | `currentWarProvider(tag)` | 현재 클랜전 |
| 버튼 | `ongoingWarProvider(tag)` | 준비일·전투일일 때만 전쟁, 그 밖과 오류는 null |
| 버튼 | `ongoingLeagueProvider(tag)` | 리그 그룹이 준비일·전투일일 때만 그룹, 그 밖과 오류는 null |
| 리그전 | `leagueGroupProvider(tag)`, `cwlWarProvider(warTag)` | 그룹, 경기 하나 |
| 리그전 | `cwlSeasonProvider(tag)` | 그룹을 받은 뒤 `#0`을 뺀 모든 경기를 한꺼번에 받는다(최대 7라운드 × 4경기) |
| 공통 | `clockProvider` | 현재 시각(테스트에서 고정) |

- "정보 보기" 버튼은 일반 전쟁 조회가 **끝나고** 전쟁이 없을 때만 리그 그룹을 조회한다. 조회 중에 미리 부르지 않아 요청을 아낀다.

### 4.3 계산 규칙
| 규칙 | 위치 | 내용 |
|---|---|---|
| 태그 입력 | `tag.dart` | 1장 참고 |
| 멤버 정렬 | `clan/clan_members.dart` | 직책(리더 → 공동대표 → 장로 → 멤버) → 타운홀 높은 순 → 이름(대소문자 무시) → 태그 |
| 리그전 기록 제외 | `clan/clan_providers.dart` | 결과가 없고 1인당 공격이 1회인 로그 항목은 리그전으로 보고 전쟁 로그에서 뺀다 |
| 레이드 공격권 | `clan/capital_raid_providers.dart` | 전체 = `attackLimit + bonusAttackLimit`. 레이드 목록에 없는 멤버는 `0/5`. 공격 기록은 있는데 멤버 목록이 비어 있으면 표시하지 않는다 |
| 승리 전망 | `war/war_outlook.dart` | 별 → 파괴율 순서로 승부를 가린다. 남은 공격 = 팀 크기 × 1인당 공격 − 사용한 공격. 얻을 수 있는 별 = 상대 기지마다 `3 − 지금까지 최고 별`의 합. 필요한 별 = 별 차이 + 1. 상대의 남은 공격은 반영하지 않는 추정이다 |
| 경기 방향 맞추기 | `cwl/cwl_stats.dart` `orientTo` | 우리 클랜이 `opponent`에 있으면 `clan`과 바꾼다. 리그전 응답에 없는 `attacksPerMember`는 1로 채운다 |
| 리그 순위 | `cwl/cwl_stats.dart` `cwlStandings` | 전투일·종료 경기만 센다. 점수 = 별 합계 + 끝난 경기 승리 × 10. 같으면 총 파괴율(경기별 파괴율 × 팀 크기의 합)이 높은 순. 별과 파괴율이 모두 같으면 무승부(보너스 없음) |
| 멤버 성적 | `cwl/cwl_stats.dart` `cwlMemberStats` | 전투일·종료 경기만 센다. 출전 라운드, 공격 수, 별, 3성 수, 평균 파괴율(공격당). 별 → 평균 파괴율 순 정렬 |
| 타운홀별 최고 레벨 | `player/level_caps.dart` | `level_caps.json`의 표에서 `[타운홀 − 1]` 위치 값을 쓴다. 0이거나 표에 없으면 표시하지 않는다. 공식 API의 `maxLevel`(게임 전체 최대)은 쓰지 않는다 |
| 이미지 이름 | `player/game_assets.dart` `gameSlug` | 소문자로 바꾸고 `.`과 `'`를 지운 뒤 영문·숫자 외 문자를 `-`로 바꾼다. 예: `P.E.K.K.A` → `pekka`, `Archer Queen` → `archer-queen` |

### 4.4 다국어
- 문구는 `apps/mobile/lib/l10n/app_{ko,en,ja}.arb`에 둔다. 영어 파일이 기준(template)이다.
- 새 문구는 세 언어에 모두 넣고 `flutter gen-l10n`으로 `app_localizations*.dart`를 만든 뒤 함께 커밋한다.
- 숫자나 이름이 들어가는 문구는 자리표시자(`{n}`, `{used}/{total}`)를 쓴다.

### 4.5 화면 공통 규칙
- 본문 폭은 `contentMaxWidth`(640) 하나로 맞춘다. 나란히 보기는 `splitViewMinWidth` 이상에서만 켠다.
- 목록 화면은 당겨서 새로고침을 지원한다.
- 통계 아이콘은 Material 아이콘만 쓴다.
- 클랜전 본문(`WarView`)은 일반 클랜전과 리그전 경기가 함께 쓴다. 남은 시간 문구는 1분마다 다시 그린다.
